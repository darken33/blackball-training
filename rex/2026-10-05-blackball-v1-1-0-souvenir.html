À retenir pour le REX

  • La salle est bonne pour diverger ; la traçabilité demande une spec écrite avant le code.
  • Le test écrit d'abord a tenu (verify-stats vert du premier coup) ; l'UI n'a aucun test, donc les défauts en usage réel restent à relever.
  • Mesures relevées de l'extérieur : ~1h30, ~6 %. Comparaison avec le cycle BMad indicative (périmètres différents).
  • Prochaine étape : tester l'onglet Stats en salle de billard, puis compléter le REX.

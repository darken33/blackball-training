- (decision) [ASSUMPTION] Stack retenue: Vite 8 + React 19 + TypeScript, PWA via vite-plugin-pwa (Workbox), persistance via Dexie 4 (IndexedDB). Choix d'un starter connu et courant plutot qu'un stack hand-roll, adapte a un dev solo niveau intermediaire, greenfield, sans backend.

- (decision) Paradigme retenu: architecture en couches a coeur de domaine pur (domain-core layered) — (1) domain: moteur de notation + catalogue de contenu, fonctions pures sans I/O; (2) application: orchestration de session (etat courant, transitions essai/exercice/session); (3) adapters: persistance (Dexie), rendu (composants React + SVG). Sens de dependance impose UI -> application -> domain, jamais l'inverse; persistance appelee uniquement depuis application.

Previent une divergence entre score stocke et regle de calcul si le moteur evolue. Fonde sur addendum.md (le moteur ne peut pas etre un champ plat) et FR-6.
- (decision) [ADOPTED] Format des schemas: SVG genere depuis des coordonnees de grille structurees (pas d'images statiques par exercice). - (decision) [ADOPTED] Persistance incrementale: chaque essai soumis (tap bille ou faute) declenche une ecriture Dexie immediate du fait brut avant d'avancer l'etat UI; la session en cours en IndexedDB est la source de verite pour la reprise (pas seulement l'etat composant React). - (decision) [ADOPTED] Frontiere abandon/interruption: un seul point de code (le handler de confirmation Abandonner) supprime une session en cours; aucun handler de cycle de vie/visibilite (blur, visibilitychange, background) ne supprime ou modifie une session.
